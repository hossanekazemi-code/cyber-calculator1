PHONE SETUP

1. Put app.py, templates/, and static/ in the same project folder.
2. Replace the old app.py with CyberCalculatorWeb_phone_ready.py and rename it to app.py.
3. Put Run_CyberCalculator_Phone.bat in the same folder as app.py.
4. Double-click Run_CyberCalculator_Phone.bat.
5. Read the PHONE URL shown in the console, e.g. http://192.168.1.7:5000/
6. Connect the phone and PC to the same Wi-Fi and open that URL on the phone.
7. Keep the batch window running while using the site.

If Windows asks for network access, allow it on Private networks.
The launcher also attempts to add an inbound firewall rule for TCP 5000.
